# AGENTS.md — сторонние плагины

Контекст решений в `Assets/Plugins`. Собственный код проекта находится в `Assets/Code`.

## Правила работы

- Vendor-код не редактировать без отдельного запроса. Интеграцию делать через `Assets/Code`.
- Наличие плагина не означает, что проект уже использует его архитектуру или runtime-компоненты.
- Demo, Example и Walkthrough — справочный контент, не источник игровых зависимостей.
- Не удалять ассеты и не менять их GUID при документировании или подключении плагина.
- Перед обновлением читать локальный changelog и проверять пересечения с существующими решениями.

## Пересекающиеся решения

- `GOPainter`, `PrefabPainter`, `EnviroSpawn` решают близкие задачи размещения объектов. Для новой работы сначала выбрать один инструмент по задаче: ручная кисть, пресеты или массовый scatter.
- `Kartograph` — генератор уровней, не замена существующим игровым сценам и не инструмент ручной расстановки.
- `HomebrewIK` отвечает за стопы, `KinematicCharacterController` — за движение; это разные слои, их можно комбинировать только через явную интеграцию.
- `Graphy` использовать для отладки производительности, не как постоянный элемент игрового UI.

## Платформенные библиотеки

`Android/` и `iOS/` содержат платформенные native-зависимости, а не самостоятельные gameplay-плагины. Не перемещать и не удалять: фильтры платформы и настройки импорта связаны с этими путями.

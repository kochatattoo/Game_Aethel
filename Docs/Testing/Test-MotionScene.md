# Test_MotionScene

Дата: 30.10.2026. Самостоятельный Editor-полигон движения одного существующего персонажа, без загрузки кампании и пользовательских слотов.

## Запуск

1. Сохранить текущую рабочую сцену.
2. Unity → **Tools → PetProject → Motion → Open Test Motion Scene**.
3. Нажать Play, затем щёлкнуть внутри **Game View**, чтобы передать ему фокус.
4. В окне **Test Motion** выбрать **Обычное** или **В бою**. Окно можно переместить/закрепить рядом с Game View.

Сцена: `Assets/_project/Scenes/TEST/Test_MotionScene.unity`. В основной список сцен сборки она не добавлена.

## Управление

| Действие | Управление |
|---|---|
| Свободное движение / подтверждение клеточного пути | ЛКМ по допустимой поверхности |
| Предпросмотр тактического пути | Навести мышь на клетку |
| Вращение камеры | ПКМ + движение мыши |
| Поворот на 45° | Q / E, при фокусе Game View |
| Масштаб | Колесо, указатель внутри Game View |
| Исходный ракурс | F или «Фокус камеры» |
| Восстановить ОД | «Новый тестовый ход» |
| Вернуть героя к spawn | «Сброс героя» |

Начальный бюджет — **6 ОД**, клетка — **1×1 unit**, обычная цена входа — **1 ОД**, фиолетовый участок — **2 ОД**. Настройки предназначены для полигона и не утверждают баланс GDD. Пресеты 3/6/12 выбираются до Play.

В обычном режиме герой движется по NavMesh. При входе в тактику он плавно выравнивается по доступному центру. В тактике показывается путь, цена и остаток/нехватка ОД: зелёный участок доступен, красный превышает бюджет, голубой обозначает исполняемый путь. Если полного бюджета нет, весь запрос отклоняется. Выход в обычный режим во время движения ожидает завершения принятого пути.

## Площадка

- Габариты 100×100 по X/Z, от −50 до +50; 10 000 логических клеток.
- Открытая зона со spawn, кубы/сферы, тонкая стена, широкий/узкий проходы.
- Пологий и средний пандусы с платформами; отдельный слишком крутой склон.
- Замкнутая недостижимая площадка и участок с повышенной ценой.
- Воспроизводимые дополнительные блоки по seed.

В Play локально отображается сетка вокруг героя. «Показать всё поле» включает полный отладочный показ. Сетка состоит из общего mesh, клетки не являются отдельными GameObject. Геометрия сетки кешируется отдельно от preview пути.

В Edit Mode кнопка **Generate + Bake NavMesh (Undo)** заменяет только GeneratedRoot и обновляет навигацию. Сначала выйти из Play. Ручные объекты снаружи GeneratedRoot сохраняются. После Undo/Redo или изменения геометрии требуется повторный bake; устаревшие данные не допускаются к запуску. Команда **Rebuild And Save Test Scene** делает rebuild и сохраняет текущую тестовую сцену.

## Реализация

| Область | Файлы/решение |
|---|---|
| Конфигурация/геометрия | `Modules/Gameplay/MotionTest/MotionTestConfig`, `MotionTestWorld`, `MotionSurface` |
| NavMesh → сетка | `SurfaceGridMap`: опора, высота, clearance и допустимые соседние переходы |
| ОД/правила | `Modules/Tactics/Runtime/MotionTestSession`: один герой, атомарный отказ, ревизия, idempotent command ID |
| Общий путь | Существующие GridBoard/GridPathfinder; добавлена неизменяемая карта запрещённых направленных рёбер |
| Unity-исполнение | `MotionTestController`: свободное NavMesh-передвижение, выравнивание и точное следование клеточным сегментам |
| Персонаж | Отдельный `Prefabs/Tests/MotionTestHero.prefab` с исходными моделью, rig, Avatar, controller и HeroAnimator/HeroPathFollower |
| Камера | Установленный Cinemachine 3.1.5, Orbital Follow + Rotation Composer; собственный драйвер Input System |
| Отладка | `Editor/MotionTest`: окно, безопасное создание, rebuild, фильтр фокуса и runtime-проверки |

Пути Modules/Editor в таблице указаны от `Assets/_project/CodeBase`. Исходный общий prefab героя и его controller не переписываются. В тестовом экземпляре root motion и animation events выключены; боевые/аудио/диалоговые компоненты исключены из оболочки. Анимационные StateMachineBehaviour получают существующий HeroAnimator. Шаги и боевой звук в этот тест не входят.

Сеточные правила не обращаются к UnityEngine. Единственный владелец логической клетки и ОД — session; после commit модель воспроизводит принятый маршрут. Во время этого исполнения новый тактический ввод заблокирован. Обычный motor и клеточный motor не управляют Transform одновременно.

## Проверки

- Native Unity Test Runner, EditMode, фильтр **PetProject.Tactics.Tests**: **31/31 passed**, 0 failed, 0 skipped. Это 24 существующих метода D1 и 7 новых методов MotionRulesTests. Поле testCount обёртки MCP не используется как число уникальных методов.
- **Tools → PetProject → Motion → Run Runtime Checks**: проверка реальных Unity-компонентов в Play Mode, с выходом обратно в Edit Mode. Результат: `Library/MotionTest/runtime-checks.json`.
- `success=true`, `saveIsolation=true`: пройдены standalone-запуск, ввод камеры через Input System, обычное движение/анимация, недостижимая цель, сетка/ОД/отказ, выход во время движения, подъём/спуск и 20 переключений режима. Проверка сравнивает hashes JSON/backup-файлов под persistentDataPath до/после, не записывая их содержимое в отчёт.
- Нативный UI: визуально осмотрены обычное движение, сетка и пандус; выполнен обычный клик движения и нажатие «В бою» в EditorWindow. Q/F, orbit с ПКМ и zoom проверены также через настоящий поток Input System с временными тестовыми устройствами; устройства удаляются после сценария.
- **Tools → PetProject → Motion → Run Editor Checks**: финальный `editor-checks.json` подтверждает сохранность ручного объекта, восстановление ссылки GeneratedRoot при Undo, Redo и обязательное устаревание bake. Первая проверка обнаружила потерю ссылки при differential Undo; исправлено полным снимком владельца перед удалением корня. Старое исключение этой проверки может оставаться в истории Console, финальный повтор успешен.
- Console после финальных runtime-проверок: новых ошибок не обнаружено. Предупреждения окружения учитываются отдельно.

Снимки камеры: `Library/MotionTest/normal-preview.png`, `combat-preview.png`, `ramp-preview.png`. Файлы Library локальные и не являются версионируемыми исходниками. Итоговый JSON копируется в `Docs/Testing/_results` для review.

В последнем автоматическом прогоне: **9 293 доступные клетки из 10 000**, сборка сетки **58,24 ms**, последний целевой preview **0,12 ms**. Это отдельные измерения этого запуска; дальний/недостижимый запрос может стоить больше. В одном из предыдущих прогонов наблюдался preview около 17,5 ms. Полного CPU/GC/GPU-профилирования и измерений на минимальном железе не выполнялось.

## Ограничения

Это тест движения, а не полноценный Encounter: нет врагов, инициативы фракций, атак, победы, сохранения боя и отряда. Нужна одна поверхность в каждой X/Z-позиции; мосты над другим этажом не моделируются. Мир статичен; изменение препятствий во время принятого маршрута не поддерживается. Ошибка опоры останавливает исполнение и требует Reset.

Полигон проверен в Editor на Windows. Отдельная player-сборка, запуск player, аудио, другие платформы и графическое качество всей игры этой работой не подтверждаются. Точечные замеры времени grid/preview видны в окне и отчёте; они не являются полноценным профилированием или гарантией FPS.
